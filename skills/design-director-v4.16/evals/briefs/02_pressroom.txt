Design and build a browser-based visual composition editor that allows users to create simple posters using text, shapes, and colors. Users should be able to add elements to a canvas, select them, drag to reposition, resize, rotate, adjust their properties, change layer order, and delete them. Include undo and redo, keyboard shortcuts, a properties panel, and an export function. The interface should make editing operations discoverable and provide immediate visual feedback while preserving consistent state across operations.
