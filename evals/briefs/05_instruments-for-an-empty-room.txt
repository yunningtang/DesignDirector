Design and build an interactive 3D virtual exhibition inside a web browser. Create a small gallery containing at least six original exhibits represented by 3D objects. Users should be able to navigate the space, rotate the camera, inspect individual objects, and access contextual information about each exhibit. Include clear navigation guidance, object selection feedback, camera controls, and a way to return to an overview of the gallery. Focus on spatial usability, discoverability, performance, and interaction quality. The experience should work without requiring VR hardware.
